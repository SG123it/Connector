## 📖 О проекте
**Connector** — это консольная программа, которая избавляет от необходимости вручную отслеживать изменения и копировать файлы между папками. Достаточно один раз настроить конфигурацию, и синхронизация будет выполняться по вашей команде.

В основе работы лежит простая, но гибкая модель **родительской (`Parent`)** и **дочерних (`Child`)** папок.

> 💡 **Главная идея:** есть одна «главная» папка (`Parent`), изменения из которой распространяются на одну или несколько подчинённых папок (`Child`). Конфигурационный файл `Parent` переименовывать нельзя — это якорь всей схемы.

|                                                 |                                                                                                                                                  |

## 🚀 Быстрый старт

### 1. Клонирование и сборка

```bash
git clone https://github.com/SG123it/Connector.git
cd Connector
```

Сборка через CMake:

```bash
mkdir build && cd build
cmake ..
cmake --build . --config Release
```

> **Требования:** компилятор с поддержкой C++17, CMake 3.15+.
> Для Windows рекомендуется использовать MSVC (Visual Studio 2019/2022) или MinGW.

### 2. Настройка конфигурации

Создайте файл `ConnectorConfig.jccf` в **родительской** папке (той, которая будет источником изменений).

Пример структуры файла:

```json
{
  "type": "Parent",
  "path": "C:/Sync/MainFolder",
  "Child": {
    "0": { "path": "C:/Sync/BackupFolder" },
    "1": { "path": "D:/Archive/ProjectCopy" }
  }
}
```

- `type: "Parent"` — помечает текущую папку как родительскую.
- `path` — абсолютный путь к папке.
- `Child` — список дочерних папок, которые будут синхронизироваться с родительской.

> ⚠️ **Важно:** конфигурационный файл родительской папки переименовывать нельзя. Именно по нему программа определяет «главную» директорию.

### 3. Запуск синхронизации

Поместите исполняемый файл `Connector` (или `Connector.exe` в Windows) в любую из папок, участвующих в синхронизации, и запустите его.

Программа прочитает конфигурацию, определит роли папок и выполнит синхронизацию.

## 🧠 Как это работает

```
📁 Parent (главная папка)
├── 📄 ConnectorConfig.jccf   ← якорный конфиг
├── 📁 Файл A
└── 📁 Файл B
        │
        ├──► 📁 Child 1 (копия)
        └──► 📁 Child 2 (копия)
```

1. Программа находит конфигурационный файл.
2. Определяет, является ли текущая папка `Parent` или `Child`.
3. Считывает список дочерних путей.
4. Выполняет синхронизацию файловой структуры.

Такая модель позволяет держать центральную папку в актуальном состоянии и быстро разворачивать её копии в нужных местах — например, для бэкапа, переноса на другой диск или публикации в облачную директорию.
