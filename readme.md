<h1 style="text-align: center;">Connector - Программа для синхронизиции папок</h1>

<h2><b>

Данная программа помогает решить проблему с ручной синхронизацией папкой. 
<br><br>
Чтобы начать процесс синхронизации запустите в любой из папкок конфигурационный файл программы c расширением .jccf

</b></h2>

<br><br><br>

<h3><b>У программы есть понятие parent папка и child папка</b></h3>
<h3><b>Parent папка - главная папка.</b></h3>
<h3><b>Child папка - Папка которая синхронизируется с родительской папкой.</b></h3>



<hr>
<h3><b>
Предупреждение! Родительский конфигурационный файл переименовывать нельзя
</b></h3>
